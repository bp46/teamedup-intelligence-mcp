# TeamedUp Intelligence — Data Compliance Summary

Public labor-market compensation data only. No personal candidate data is collected or stored.

## Mainland China
- Personal Information Protection Law (PIPL)
- Cybersecurity Law
- Data Security Law
- Regulations on Internet Information Service (ICP)
- Anti-Unfair Competition Law (public data scraping)

## Hong Kong SAR
- Personal Data (Privacy) Ordinance (PDPO)
- Code of Practice on Human Resource Management (PCPD)
- Privacy Guidelines: Monitoring and Personal Data Privacy at Work

## Taiwan
- Personal Data Protection Act (PDPA)
- Employment Service Act (privacy data restrictions)
- Regulations Governing Personal Information File Security Maintenance Plan (HR recruitment industry)

## Singapore
- Personal Data Protection Act (PDPA)
- Employment Act
- Tripartite Guidelines on Fair Employment Practices

## Vietnam
- Personal Data Protection Decree 13/2023/ND-CP (and 2025 Law on Personal Data Protection)
- Labor Code 2019
- Decree 356/2025 (amending Decree 13)

## General
- GDPR (EU) — where applicable for EU-origin data
- Data minimization: only aggregated salary/role/company metadata retained; no candidate PII, resumes, or application data.
- All sourced from publicly posted job listings on employer career pages and job boards.
